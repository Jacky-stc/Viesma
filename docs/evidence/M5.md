M5.1 成長保留於匿名角色的伺服器記憶體，在換圖與重連保留期內沿用。完整 EXP／ground grants 記憶體交易屬 M5.5，PostgreSQL durability 屬 M7。

- **本機驗收（2026-11-25）**。Windows 11 26200、Node.js 24.22.3／pnpm 11.19.0。Typecheck、lint、套件邊界、格式、464 項 Vitest、正式建置、七張地圖與素材驗證皆通過。完整 Chromium 159.0.8154.6 smoke 共 22 項，序列多人階段 8／8，其餘 14／14。多人驗收包含 150 ms RTT 換圖與重連。預設伺服器埠已有服務，使用 `VIESMA_SERVER_PORT=25767`。
- **M4.5 耐久回歸**。同一台 i7-1355U（12 logical CPUs）、16 GiB 的 Windows 主機，以四角色及兩房運行 600.044 秒／18,000 ticks。26 次循環各驗證死亡、返村、重連、怪物重生與 receipt 提交／釋放。14 次 tick backlog 全部恢復，峰值 4 ticks。結束時待處理意圖與保留 receipt 均為 0，程序錯誤 0，清理後排程停止。 [耐久命令](../../apps/server/test/run-shared-combat-endurance.mjs)
- **GitHub Actions**。Ubuntu CI 於遠端基線 `23762f2` 通過。M5.1 的驗證紀錄來自本機工作樹。 [基線 CI](https://github.com/Jacky-stc/Viesma/actions/runs/45629833638)
